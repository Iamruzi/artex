# Turnstile 官方测试矩阵

以下值来自 Cloudflare 官方文档，仅用于开发和自动化测试。

| 场景 | Sitekey | Secret |
|---|---|---|
| 可见组件始终成功 | `1x00000000000000000000AA` | `1x0000000000000000000000000000000AA` |
| 可见组件始终失败 | `2x00000000000000000000AB` | `2x0000000000000000000000000000000AA` |
| 隐形组件始终成功 | `1x00000000000000000000BB` | `1x0000000000000000000000000000000AA` |
| 隐形组件始终失败 | `2x00000000000000000000BB` | `2x0000000000000000000000000000000AA` |
| 强制交互挑战 | `3x00000000000000000000FF` | 按具体成功/失败验证场景选择测试 secret |
| 模拟 token 已使用 | 任一匹配测试 sitekey | `3x0000000000000000000000000000000AA` |

测试 sitekey 可用于 localhost 和测试域。测试 secret 只接受 dummy token；生产 secret 只接受真实 token。客户端和服务端必须同时切到测试配置，否则结果没有意义。
